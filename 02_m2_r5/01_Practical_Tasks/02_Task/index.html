LINUX OPERATING SYSTEM

Introduction

Linux is a free and open-source operating system created by Linus Torvalds. It is widely used in computers, servers, mobile phones and supercomputers.

Important Information

Developer : Linus Torvalds
Initial Release : 17 September 1991
Written In : C Language
License : GNU General Public License (GPL)
Type : Open Source Operating System
