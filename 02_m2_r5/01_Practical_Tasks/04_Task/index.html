6. Important Technology Terms

HTML
HyperText Markup Language used to structure web pages.
CSS
Cascading Style Sheets used to style and design web pages.
JavaScript
A programming language used to add dynamic behavior to web pages.
HTTP
HyperText Transfer Protocol used for communication between web browsers and servers.
URL
Uniform Resource Locator used to identify a resource on the internet.
API
Application Programming Interface that allows software applications to communicate with each other.
SQL
Structured Query Language used for managing relational databases.
Git
A distributed version control system used to track changes in source code.
