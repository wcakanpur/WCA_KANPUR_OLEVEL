CSS Background Properties

1. background

The background property is a shorthand property used to define multiple background properties in a single declaration.

It can be used to specify background color, image, position, size, repeat and other background settings.

2. background-color

The background-color property specifies the background color of an element.

It can accept color values such as names, hexadecimal values, RGB values and other valid CSS color formats.

3. background-image

The background-image property is used to place an image behind the content of an element.

A background image can be specified using the url() function.

4. background-repeat

The background-repeat property controls whether a background image should repeat horizontally, vertically, in both directions or not repeat.

Common values include repeat, repeat-x, repeat-y and no-repeat.

5. background-position

The background-position property specifies the starting position of a background image inside an element.

Common positions include top, bottom, left, right and center.

6. background-size

The background-size property controls the size of the background image.

Values such as cover, contain and specific dimensions can be used to control the image size.

7. background-attachment

The background-attachment property determines whether the background image scrolls with the element or remains fixed relative to the viewport.

Common values include scroll and fixed.

8. background-clip

The background-clip property specifies the area within which the background is painted.

Common values include border-box, padding-box and content-box.

9. background-blend-mode

The background-blend-mode property defines how multiple background layers blend with each other.

Different blend modes can create different visual effects between a background image and background color.

9.1 normal

The normal value displays the background layers without blending them with each other.

9.2 multiply

The multiply value combines the colors of the background layers and generally produces a darker result.

9.3 screen

The screen value generally produces a lighter result by blending the background layers.

9.4 overlay

The overlay value combines the effects of multiply and screen depending on the underlying colors.

9.5 darken

The darken value keeps the darker color from the corresponding background layers.

9.6 lighten

The lighten value keeps the lighter color from the corresponding background layers.

9.7 color-dodge

The color-dodge value increases brightness and can create a strong glowing effect.

9.8 color-burn

The color-burn value generally produces a darker and more intense color effect.

9.9 hard-light

The hard-light value creates a strong contrast between the background layers.

9.10 soft-light

The soft-light value produces a softer contrast effect compared with hard-light.

9.11 difference

The difference value creates a color effect based on the difference between the background layers.

9.12 exclusion

The exclusion value creates an effect similar to difference but with lower contrast.

9.13 hue

The hue value uses the hue of the blending layer while preserving the saturation and luminosity of the base layer.

9.14 saturation

The saturation value uses the saturation of the blending layer while preserving other color characteristics.

9.15 color

The color value applies the hue and saturation of the blending layer while preserving luminosity.

9.16 luminosity

The luminosity value uses the luminosity of the blending layer while preserving the hue and saturation of the base.
